# 2026-10-20 — defaults = the author's tuned look; High on 6-8 GB GPUs

Pages: using/settings (graphics presets, display), rendering/clouds, rendering/sea, rendering/aurora, accuracy (extinction).

- A packaged build has no settings.json: a fresh install is the compiled defaults + the first-run preset. The author's
  tuned settings were baked into the defaults (2 significant figures): clouds sun gain 2.3, multiple scattering 0.27,
  history weight 0.046, light march 2500 m, mid layer density 0.3, cloud sunlight Rayleigh 0.86, accumulation 39;
  flat cloud layers coverage 0.57 / sun 1.8; far sea ripple 1.7, ripple size 1.5, wave sharpness 0.1; aurora sheets
  1.4 / spacing 0.34 deg / crisp 0.77 / folds 1.1, storm features 1.2, blue rays 0.004, arc systems 2, storm red 1.1,
  coverage freq 0.58 / az 3.1, shimmer 0; extinction 0.18 mag; mirror boost 1000.
- Display defaults: Automatic render scale OFF, Clouds follow render scale OFF; the cloud march's adaptive rate and
  sparse-when-still OFF (full rate always).
- First-run preset: a discrete GPU with >= 5.5 GiB of VRAM starts on High (= the defaults at 100% render scale);
  smaller discrete GPUs Medium, integrated Planetarium, MoltenVK on non-Apple Potato (unchanged).
- Presets now also set the cloud rate and "Clouds follow render scale": High / Ultra full rate, compute at full size;
  Low / Medium / Planetarium / Potato adaptive rate + sparse when still + follow the render scale (their old, measured
  configuration). Changing the render scale or that toggle by hand makes the preset Custom (a named preset re-derives
  them on every load, so the change used to be lost).
- Verified: a fresh harness run on an RTX 3070 Ti vs the author's settings.json at four views (cumulus day, sunset coast,
  orbit, night city): mean |diff| 0.01-0.32 levels.
