## Now
The interface has four colour themes, chosen on the Display tab's WINDOW section ("UI theme": Default, Navy,
Night red, Midnight; settings.json `display.ui_theme` = "default" / "navy" / "night" / "midnight", default
"default"). Default is the
near-black panels with the red accent; Navy is blue-black panels with a deep azure accent; Night red keeps the
whole interface dim red so it does not spoil dark adaptation: every colour the UI draws, including icons, the 3D
view, bookmark and report thumbnails, is mapped to red at its brightest channel; Midnight keeps Default's accent and text on darker, more opaque near-black panels. The theme also applies to the
startup graphics chooser (read from settings.json before it shows). It colours the interface only, not the sky.
All UI colours live in one table, `UI_PALETTE` in `src/simulations/UIPalette.h`, one column per theme.

## History
Before 2026-10-14 the palette (`Pal::`) was compile-time constants, and about 60 colours were literals at their
call sites (text fields, cards, sliders, toasts, the tutorial's keycaps); those moved into the table.
